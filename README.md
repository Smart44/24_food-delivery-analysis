# Food Delivery Logistics Analysis

### Data Source
The dataset used in this analysis is sourced from Kaggle: 
[Food Delivery Indonesia Analysis](https://www.kaggle.com/code/boiniabhiram/fooddelivery-indonesia-analysis)

### Project Overview
This project analyzes 8,500 food delivery records to identify the main causes of delays. As a former courier with 5,000+ deliveries, I used Python to verify if my professional intuition matches the data.

### Key Insights
- **Congestion vs. Distance:** Scatter plots show significant delays even at short distances (1-2 km), suggesting kitchen or dispatch bottlenecks.
- **Peak Hour Impact:** Analysis shows waiting times increase by 25-30% during lunch (11:00-14:00) and dinner (17:00-21:00) peaks.
- **Data Quality:** Handled 20% missing/invalid timestamps to ensure accurate hourly distribution.

### Tech Stack
- **OS:** Linux
- **Language:** Python (Pandas, Seaborn, Matplotlib)
- **Environment:** Jupyter Notebook, venv
